# דמה — הפורום להגנת הצרכן

[פתיחת הדמו](https://haganat.github.io/demo/)

סביבת הצגה אינטראקטיבית בעברית, המבוססת על העיצוב ותהליכי העבודה של הפורום.
זהו מאגר ההפצה של הדמו. הוא מכיל רק את האתר הסטטי המוכן, ללא היסטוריית הפרויקט או קוד השרת.

## נתוני הדגמה

| סוג | כמות בסיס |
| --- | ---: |
| אנשי קשר | 6,000 |
| תיקים | 2,400 |
| פניות טלפוניות — ידע פון ו־GIS | 18,000 |
| שיחות דואר | 7,200 |
| שיחות וואטסאפ | 4,800 |
| תשלומים | 14,400 |
| יועצים | 36 |
| חברות פיקטיביות | 30 |
| דוגמאות לימוד AI | 126 |

כל הנתונים נוצרים באופן סינתטי בדפדפן. אין במאגר ייצוא של נתוני פרוד.
כתובות הדואר משתמשות ב־example.invalid; מספרי הטלפון אינם ניתנים לחיוג.
הסכומים, התוכן, הזהויות והמדדים מיועדים להדגמה בלבד.

## הצגה מומלצת

1. פתחו את לוח הבקרה ולחצו **התחלת תרחיש חי**.
2. הפעילו **סיכום וסיווג**, **ניסוח תשובה**, ו־**התאמת יועץ**.
3. העבירו את התשובה לטיוטה, ערכו ושלחו בדמו.
4. פתחו תיק מהפנייה, שנו סטטוס והוסיפו הערה.
5. פתחו את איש הקשר להצגת היסטוריה מאוחדת מכל הערוצים.

חיפוש, סינון, דפדוף, תיקים, תשלומים, יועצים ומאבקים זמינים מהתפריט.
מדריך ההצגה ואיפוס הדמו נמצאים בסרגל העליון.

## אופן הפעולה

- ה־AI הוא **סימולציה מפורשת מבוססת תרחישים**, עם תוצאות מותאמות לנתונים שנבחרו. הוא אינו מודל שפה חי.
- הודעות, הפניות ליועצים ותשלומים הם פעולות דמה. לא נשלחים הודעות או חיובים אמיתיים.
- שינויים נשמרים ב־localStorage בדפדפן של הצופה בלבד; לכל צופה הדגמה עצמאית.
- איפוס מחזיר את מאגר הדוגמה. חלון גלישה פרטי מתחיל הדגמה נפרדת.
- אין API, אימות ארגוני, מפתחות או חיבורי צד שלישי. מדיניות CSP אוסרת חיבורי רשת מהאפליקציה.
- ניווט hash מאפשר קישורים ישירים ורענון ב־GitHub Pages.
- תאריכים נוצרים יחסית למועד פתיחת הדמו הראשון ונשארים יציבים עד לאיפוס.

הריפו הסטטי ניתן להרצה מכל שרת קבצים, ללא התקנה או backend.
למשל: `python -m http.server 8080`, ואז פתיחת `http://localhost:8080`.

לוגו ועיצוב הפורום נשמרו לצורכי ההדגמה. רישיונות רכיבי צד שלישי נמצאים בתיקיית licenses.
