# הפורום להגנת הצרכן

[פתיחת המערכת](https://haganat.github.io/demo/)

מאגר הפצה סטטי. הממשק, המסכים, התפריטים והטפסים נבנים מקוד המערכת בגרסת 141d5fe0.
שכבת התקשורת מוחלפת באחסון מקומי ונתונים סינתטיים לצורך הצגות; השרת המקורי אינו כלול.

| נתונים | כמות בסיס |
| --- | ---: |
| אנשי קשר | 6,000 |
| תיקים | 2,400 |
| פניות ידע פון ו־GIS | 18,000 |
| שרשורי דואר | 7,200 |
| שיחות וואטסאפ | 4,800 |
| תשלומים | 14,400 |
| יועצים | 36 |
| חברות | 30 |
| מסמכים | 2,400 |
| דוגמאות לימוד | 126 |

כל הזהויות, הפניות, המדדים והתשלומים סינתטיים. לא הועתקו רשומות לקוח או היסטוריית Git מהמערכת הפרטית.
ה־AI מפיק סיכומים, טיוטות וקיבוצים באמצעות תרחישים מקומיים המבוססים על הרשומה הנבחרת; אין קריאה למודל חי.
מייל, וואטסאפ, פעולות ניהול ותשלומים נשארים בדפדפן ואינם מפעילים שירותים אמיתיים.
האתר אינו מאמת חיבורים, גיבויים או מצב שרת של מערכת אמיתית. חלק מפעולות ספקים דורשות את השרת המקורי.

להצגה: פתחו כרטיס איש קשר, הפעילו רענון תובנת AI, עברו לפניית ידע פון וסיכום, ולשרשור מייל ליצירת תשובה.
אפשר לערוך הערות, ליצור תיקים ולשלוח הודעות מקומיות. השינויים נשמרים בדפדפן; חלון פרטי מתחיל סביבה חדשה.
ניווט hash תומך בקישורים ישירים וברענון ב־GitHub Pages. אין צורך בהתקנה או backend.

ui-parity.json מפרט את מודולי הממשק בבנייה. release.json כולל בדיקות SHA-256 לכל קובצי ההפצה.
רישיונות רכיבי צד שלישי בתיקיית licenses. הלוגו והעיצוב של הפורום נשמרו.
